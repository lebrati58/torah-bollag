# בְּרֵאשִׁית

Référence : בראשית א׳:א׳–ו׳:ח׳

בריאת העולם, אדם וחוה בגן עדן, היציאה מן הגן, קין והבל והדורות עד נח.

## Continuité
בסוף הפרשה מכירים את נח. הסיפור שלו ממשיך בפרשה הבאה.
