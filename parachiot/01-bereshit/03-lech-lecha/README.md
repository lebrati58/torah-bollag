# לֶךְ־לְךָ

Référence : בראשית י״ב:א׳–י״ז:כ״ז

אברם יוצא לכנען עם שרי ולוט. הוא יורד למצרים, נפרד מלוט ומציל אותו. מסופר על הברית, על הגר ולידת ישמעאל ועל שינוי השמות לאברהם ולשרה.

## Continuité
ההבטחה על בן לשרה תוביל לבשורה שבפרשת וירא.
